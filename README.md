# MCE6001 随机过程 · 期末复习网页

单文件、离线可用的期末复习网页：**课件考点总结 × 作业全题全解 × 题型套路 × 公式速查**。

- 🌐 在线版（iPad / 手机）：GitHub Pages 自动部署，见仓库 Settings → Pages 或仓库 About 链接。
- 💻 离线版（电脑）：克隆仓库后直接用浏览器打开 `index.html` 即可（单文件，无任何外部依赖，数学公式与字体全部内嵌）。
- 🖨️ 支持打印 / 导出 PDF；支持深色模式、搜索、答案折叠（默认折叠，先自测再看答案）。

## 内容结构
| 板块 | 说明 |
|------|------|
| 题型地图 | 10 道作业题 ↔ 课件章节 ↔ 一句话套路 |
| 作业 1 / 作业 2 | 全部题目 + 完整解答 + 考点与套路（答案默认折叠） |
| 公式速查 | 四章核心公式一页速查 |
| 课件总结 Part 1–4 | 定义 / 定理 / 公式 / 常考题型套路 / 易错点 |

## 重新构建
```bash
npm install
node build.mjs   # 读取 content/*.md 与 ../_content/summary_*.md，生成单文件 index.html
```

内容源文件在 `content/`（作业与速查）与上级目录 `_content/`（课件总结 Markdown）。
